spendlog ⬡
shared expense tracker — google sheets backend
Step 1 — One-time Google Cloud setup
1
Go to console.cloud.google.com → create a new project (top-left dropdown → New Project)
2
Enable the Google Sheets API for that project
3
Go to APIs & Services → OAuth consent screen → choose External → fill App name (anything) → save. Under Test users, add both your email addresses.
4
Go to Credentials → Create Credentials → OAuth client ID → choose Web application → under "Authorised JavaScript origins" add null (for local file use) and your site URL if hosting. Copy the Client ID.
Step 2 — Your Google Sheet
5
Go to sheets.new → Row 1 headers exactly: Date | Amount | Category | Note | Who | ID
6
Share the sheet with Anyone with the link → Editor. Copy the Sheet ID from the URL: /spreadsheets/d/SHEET_ID/edit
Step 3 — Connect
These are saved in your browser only. The other person opens the same HTML file and enters the same Client ID + Sheet ID but their own name.
